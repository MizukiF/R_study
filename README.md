# R と医療統計 勉強会

架空の **多施設RCT（降圧薬 vs プラセボ）** の疑似データを自分で作り、
整形 → 測定誤差 → 頻度論 → ベイズ → 混合モデル → ブートストラップ → 可視化 と一通り体験する。

> **この勉強会の一番のポイント**
> データを自分で作るので **「真の答え」がわかっている**。
> 各手法が真値をどれだけ当てられるか、どんなときに外すかを、自分の目で確かめられる。

## 1. 疑似データ（01）

```
施設 (8)  >  患者 (200)  >  来院 (0/4/8/12週)  >  測定 (各2回)
```

| 真のパラメータ | 値 | 意味 |
|---|---|---|
| `b_trt` | −0.8 mmHg/週 | 薬の効果。12週で **−9.6 mmHg** |
| `b_week` | −0.2 mmHg/週 | プラセボ群でも少し下がる |
| `sd_site` / `sd_pat` | 4 / 10 | 施設間・患者間のばらつき |
| `sd_visit` | 5 | 来院日ごとの変動（その日の体調など） |
| `sd_meas` | 6 | 1回ごとの測定誤差 |

わざと「汚い」データも作っている: 性別の表記ゆれ（`M`, `Male`, `m`, ` M`）、欠測コード `999`、
日付形式の混在、二重入力、横持ちの血圧表、縦持ちの検査値、血圧が高い人ほど脱落（MAR）。

## 2. データ整形（02）

- **tidy data**: 1列 = 1変数、1行 = 1観測、1セル = 1値
- 読み込んだらまず `glimpse()`, `summary()`, `count()` で眺める
- 列の追加: `mutate()`, `case_when()`, `cut()`
- **行の追加**
  - `add_row()` … 小さな表に1行足す
  - `bind_rows()` … 同じ形の表を縦につなぐ（`.id` で出所を残す）
  - `complete()` … 「無かった組み合わせ」を NA の行として足す（欠測来院が見えるようになる）
- 縦横変換: `pivot_longer()` / `pivot_wider()`
- 結合: `left_join()` の後は **行数が変わっていないか必ず確認**、`anti_join()` で取りこぼしを確認
- 想定は `stopifnot()` でコードに書く
- 保存は `rds`（factor や日付の型が残る）

## 3. 測定誤差と再現性（03）

**観測値 = 真の値 + 誤差**

| 指標 | 意味 |
|---|---|
| within-subject SD | 同じ人を繰り返し測ったときのばらつき |
| 再現性係数 = 2.77 × SD | 同じ人の2回の差の95%がこの範囲 |
| ICC | 全体のばらつきのうち「人の違い」の割合。**同日再現性と日間再現性は別物** |
| Bland–Altman | 2つの測定法の一致。平均差（系統誤差）と一致限界。**相関係数は一致の指標ではない** |

誤差が引き起こす現象:
- **回帰の希釈**: 説明変数に誤差があると傾きは 0 に近づく（信頼性係数 λ 倍）
- **平均への回帰**: 高値で選んだ人は、何もしなくても次は下がる → 対照群が必要
- 小さな再現性研究（n=10）の ICC はとても不安定

## 4. 頻度論（04）

- 連続アウトカムの RCT は **ANCOVA**（12週値 ~ 群 + ベースライン）が標準。変化量の t 検定より精度が高い
- 2値アウトカム: リスク差・リスク比・オッズ比・NNT。イベントが多いと OR ≠ RR
- **p値**: 「H0 が正しいとき、これ以上極端なデータが出る確率」。効果の大きさでも H0 が正しい確率でもない
- **95%信頼区間**: 同じ研究を繰り返すと95%の区間が真値を含む（1つの区間について「95%の確率で真値を含む」ではない）
- 多重比較: 20回検定すれば1回は偶然有意。`p.adjust()`
- サブグループ: 「こっちは有意、あっちは非有意」は根拠にならない → **交互作用**で評価
- 検出力はシミュレーションで計算できる（どんな解析にも使える）

## 5. ベイズ統計 — Null の強さ（05）

**事後分布 ∝ 尤度 × 事前分布**

「Null の強さ」の2つの意味:

**(A) データは Null（効果なし）をどれだけ支持するか**

| 方法 | 答えられること |
|---|---|
| p値 | ✗ Null を支持する証拠にはならない（p = 0.4 でも「差がない」とは言えない） |
| BF01 | Null が対立仮説の何倍データをよく説明するか。1〜3 弱い、3〜10 中程度、>10 強い |
| ROPE + HDI | 「臨床的に無視できる差（例 ±3 mmHg）」に入る確率。95%HDI が全部 ROPE 内なら実質的に効果なし |

**(B) Null 寄りの事前分布（懐疑的事前分布）をどれだけ強くするか**
- 事前分布を N(0, 20) → N(0, 3) → N(0, 1) と強くすると、事後分布は 0 に引き寄せられる
- 結論が事前分布にどれだけ依存するかを示す = **感度分析**
- BF は事前分布の幅（`rscale`）に敏感。広すぎる事前分布は Null を不当に有利にする（Jeffreys–Lindley）

このデータで見えること:
- 血圧への効果 → BF10 は数千万。圧倒的
- 性別による差（真値 0）→ BF01 ≈ 4。ROPE では「決めきれない」 = n=173 では同等性までは言えない
- イベントのハザード比 → p = 0.1 で「有意差なし」だが、P(HR < 1) ≈ 0.93、BF01 ≈ 0.9。**効果がない証拠ではなく、データ不足**
- H0 が真のとき、n を増やすと p値は一様分布のままだが BF01 は大きくなっていく

brms のチェックリスト: 事前予測チェック → 収束（Rhat < 1.01, ESS > 400, divergence なし）→ 事後予測チェック

## 6. 線形混合モデル・マルチレベル（06）

- 同じ患者の測定は似ている → 独立を仮定する `lm` は SE を間違える
  - 患者「間」の比較（群間差など）は SE を過小評価 → 偽陽性
  - 患者「内」の比較（時間変化など）は SE を過大評価 → 検出力の損
- `(1 | id)` ランダム切片、`(week | id)` ランダム傾き、`(1 | site)` 施設
- **部分プーリング**: 情報の少ない患者の推定値ほど全体平均に引き寄せられる（縮約）
- 測定を2回しているので `(1 | id:week)` を入れると **来院日の変動と測定誤差を分離して推定**できる（03章とつながる）
- 施設が8つしかないと施設間 SD の推定は不安定 → ベイズ（brms）なら不確実性ごと示せる
- 混合モデルは脱落前のデータも使うので MAR の欠測に強い

## 7. ブートストラップ（07）

- データから復元抽出 → 推定値のばらつき = 標準誤差・信頼区間
- 公式の無い統計量（中央値の差・ICC・一致限界・AUC）にも使える
- BCa 法はパーセンタイル法より正確（R ≥ 2000）
- **反復測定データは「患者」単位で再抽出**（クラスターブートストラップ）
- パラメトリック（`bootMer`）、ベイジアンブートストラップ（Dirichlet 重み）

## 8. 可視化（08）

- 棒グラフ + エラーバー（ダイナマイトプロット）ではなく、**個々の点 + 平均と CI**
- 経時データ: スパゲッティプロット + 群平均と CI
- フォレストプロット、Kaplan–Meier 曲線
- 色覚の多様性に配慮した Okabe–Ito パレット、色だけに頼らない、二重軸は使わない
- `patchwork` で並べ、`ggsave(dpi = 300)` で保存

## 9. その他の重要事項（09）

- **生存時間解析**: 追跡期間が違うなら割合の比較ではなく KM / log-rank / Cox。比例ハザードの確認
- **ROC / AUC**: 予測モデルは同じデータで評価すると性能を過大評価。較正も見る
- **欠測データ**: MCAR / MAR / MNAR。完全ケース・LOCF・混合モデル・多重代入を真値と比べる
- **再現性**: `set.seed()`、生データは書き換えない、`sessionInfo()` / `renv`、解析計画はデータを見る前に
- 報告ガイドライン: CONSORT（RCT）、STROBE（観察研究）、STARD（診断精度）、TRIPOD（予測モデル）

## 練習問題

**02 整形**
1. `labs_long.csv` で検査が欠測している患者は何人いるか。どの検査が多いか。
2. 「来院ごとの2回の測定の差が 20 mmHg を超えた」行に印を付ける列を足し、件数を数えよ。
3. 新しい施設 H09 の患者 5 人分を `tibble()` で作り、`bind_rows()` で `patients` に足せ。足りない列はどうなる？

**03 測定誤差**
4. `01_simulate_data.R` の `sd_meas` を 12 にしてデータを作り直すと、ICC・回帰の希釈・平均への回帰はどう変わるか予想してから確かめよ。
5. 1回測定の ICC が 0.8 のとき、3回平均の ICC は？（Spearman–Brown: k·ICC / (1 + (k−1)·ICC)）

**04 頻度論**
6. `b_trt` を 0（効果なし）にしてデータを作り直し、ANCOVA の p値を見よ。seed を変えて 20 回やると何回 p < 0.05 になる？
7. 変化量の t 検定と ANCOVA の検出力の差を、`sim_power()` を改造して比べよ。

**05 ベイズ**
8. 事前分布を N(−10, 2)（「効くはず」という強い信念）にしたら事後分布はどうなる？ これは許されるか？
9. ROPE を ±1 mmHg / ±5 mmHg に変えると、sex の結論はどう変わる？ ROPE は誰が決めるべきか？
10. 性別の差 (真値 0) で BF01 > 10 を得るには何人必要か、シミュレーションで調べよ。

**06 混合モデル**
11. 患者ごとに来院を 2 回に減らすと、部分プーリングの図はどう変わるか。
12. `glmer()` で「12週時点で SBP < 140 を達成したか」を施設ランダム効果つきで解析せよ。

**07 ブートストラップ**
13. n = 15 の部分集合で中央値の差のブートストラップ CI を作り、全体の結果と比べよ。

**09 欠測**
14. 01 の seed を変えて 10 回データを作り、完全ケース・LOCF・混合モデル・多重代入のどれが平均的に真値に近いか比べよ。
15. 脱落確率を「12週の（観測されない）血圧」に依存させる（MNAR）と、結果はどうなるか。
